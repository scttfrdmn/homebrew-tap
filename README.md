# Scott Friedman's Homebrew Tap

Homebrew formulae for tools by [Scott Friedman](https://github.com/scttfrdmn).

## Installation

```bash
brew tap scttfrdmn/tap
brew install <formula>
```

## Available formulae

| Formula | Description |
|---------|-------------|
| `prism` | Project scaffolding and template management |
| `cicada` | CI/CD utility |
| `bagboy` | Packaging helper |
| `aws-jupyter` | Launch Jupyter on AWS |
| `aws-rstudio` | Launch RStudio on AWS |
| `aws-vscode` | Launch VS Code on AWS |
| `aws-role-exec` | Execute commands under an AWS IAM role |
| `lens-jupyter` | Lens Jupyter integration |
| `lens-rstudio` | Lens RStudio integration |
| `lens-vscode` | Lens VS Code integration |

## Casks

| Cask | Description |
|------|-------------|
| `aws-jupyter` | Jupyter on AWS (cask) |

## Automated updates

Formulae are updated via GoReleaser when each project publishes a release.
